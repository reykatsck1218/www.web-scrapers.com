# CLAUDE.md

**Read [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md) first** — it documents this
site's architecture, conventions, deployment, and current state. Keep it updated
when you make structural changes.

## Quick reference

- **Stack:** Zola static site (`mode = "docs"`), Tanuki theme as a git submodule
  at `themes/tanuki` (run `git submodule update --init --recursive` before building).
- **Build:** `zola build` (Zola 0.22.1).
- **Deploy:** push/merge to `main` → GitHub Actions builds and publishes to the
  `gh-pages` branch automatically. Do NOT run `./build` manually (CI handles it).
- **Affiliate links:** always link to `/goto/<slug>/`, never raw affiliate URLs.
  Generated by `scripts/gen-goto.py`.
- **Site-specific values** (analytics, ad, tracking IDs) live under `[extra]` in
  `config.toml`; every ad/tracking feature is gated by its key.
- **Content frontmatter contract:** every new page needs `title` ≤ 60 chars,
  `description` 130–155 chars, `date` (and `updated` on edits), and an `[extra]`
  `faq` array matching a closing `## FAQ` section. In-body affiliate links are
  HTML anchors: `<a href="/goto/<slug>/" rel="sponsored noopener">`. New pages
  must be linked from at least one existing page (section `_index.md` minimum).
