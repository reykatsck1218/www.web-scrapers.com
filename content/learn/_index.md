Web scraping is a moving target — sites change, anti-bot systems evolve, and yesterday's script breaks tomorrow. These guides teach the fundamentals that stay useful: parsing, pagination, browser automation, proxies, and staying unblocked.

New to scraping? Start with [Web Scraping with Python](/learn/web-scraping-with-python/), then level up with [Playwright for dynamic sites](/learn/playwright-python-scraping/) and [how to avoid getting blocked](/learn/how-to-avoid-getting-blocked/). For location-sensitive data, see [US proxies with city-level geo-targeting](/learn/us-proxies/) or [China proxies for Taobao, JD.com, and Weibo](/learn/china-proxies/). Not sure which proxy tier to buy? [Shared vs. dedicated proxies](/learn/shared-vs-dedicated-proxies/) breaks down the cost and reliability tradeoffs. If you'd rather skip code entirely, [no-code web scraping](/learn/no-code-web-scraping/) covers visual data collectors for analysts and PMs.
